# 🎙️ موتور دوبله خودکار ویدیو (Automated Video Dubbing Engine)

سیستم کامل و متن‌باز برای دریافت ویدیو از یوتیوب، استخراج گفتار با `faster-whisper`، ترجمه هوشمند با `Google Gemini AI`، سنتز صدا با `Edge TTS`، همگام‌سازی زمانی دقیق (Audio Synchronization) و رندر خروجی نهایی MP4 با `FFmpeg`.

---

## ⚡ ویژگی‌های برجسته
- **کاملاً رایگان و بدون وابستگی به سرویس‌های پولی**.
- **پشتیبانی کامل از محیط‌های CPU-Only (مانند GitHub Codespaces)** و محیط‌های مجهز به GPU.
- **تولید صدای طبیعی فارسی و بین‌المللی** با پشتیبانی از بیش از ۸۰ زبان.
- **همگام‌سازی صوتی هوشمند (Lip-Sync/Timing Adjustment)** برای جلوگیری از برهم خوردن تایم‌لاین ویدیو.
- **معماری ماژولار و قابل توسعه (Provider Pattern)** برای افزودن سایر موتورهای TTS یا مدل‌های هوش مصنوعی.
- **رابط کاربری مدرن فارسی (RTL)** با وضعیت لحظه‌ای فرآیند پردازش (SSE) و پخش‌کننده ویدیوی داخلی.
- **پشتیبانی از قابلیت Resume/Recovery** در صورت بروز خطا برای جلوگیری از پردازش مجدد مراحل تکمیل‌شده.
